## 🌐 Project Overview

**Job Portal UI** is a modern job listing interface developed using React.js. It provides an organized and visually appealing platform where users can explore job openings and view important job-related information through interactive job cards.

The application focuses on a clean design, responsive layout and user-friendly experience.

## ✨ Features

- 🏢 Display company names and logos.
- 💼 Attractive job listing cards.
- 📍 Job location information.
- 💰 Salary details.
- ⏳ Experience level and job type.
- 📅 Job posting dates.
- 🔖 Save job button UI.
- 📱 Responsive user interface.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Sareenaghosur/job-portal-ui.git
```

### 2. Navigate to the Project Folder

```bash
cd React_Project01
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
